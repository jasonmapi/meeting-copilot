# 通用案例：历史线索如何复核

以下为虚构制造企业的教学情境，不对应真实客户。

| 线索 | 应如何核实 | 不能推出的结论 |
|---|---|---|
| 招聘平台声称成立多年，列有注册资本 | 核对企业全称、地域、登记机关、查询日及最新记录 | 注册资本不代表营收或预算 |
| 不同页面员工数不一致 | 保留来源、日期、统计口径，向客户确认当前范围 | 不能挑选一个数字当作已核实规模 |
| 公开专利申请涉及智能算法 | 核对申请人、原件、阶段、法律状态和技术范围 | 申请公开不代表授权、量产或实际部署 |
| 科技企业名单中出现公司名称 | 核对年度、批次、拟公示/最终阶段及有效范围 | 历史名单不自动代表当前资质 |
| 历史岗位涉及研发与测试 | 打开职责原文，区分历史线索与当前组织 | 不能直接认定客户存在某个痛点 |

把线索转为访谈问题：最近一次具体任务如何流转？哪一步有可测量的时间或错误成本？能否获得授权样本？谁负责复核和验收？客户回答仍需单独标记为陈述，而非公共证据。
