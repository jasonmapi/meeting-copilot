# 检索流程与研究维度

## 检索执行方法

1. **建立身份卡**：完整企业名＋地域；检索企业登记官方公示与官方公告，记录信用代码、成立时间、经营状态、注册地址。不同来源不同字段逐一核对；统一社会信用代码未核实时标为待确认，禁止靠名称相似并表。
2. **发现一手渠道**：企业官网、认证社交账号、政府与园区公告、展会参展名录、公开招投标。官网身份至少结合企业主体披露、已验证官方关联或备案信息核对，不凭域名猜测。
3. **建立业务画像**：产品目录、型号、应用、标准、交付模式、客户行业与渠道。把“企业自述”“公开交易记录”“分析判断”分开。客户Logo和“合作伙伴”不能直接证明近期订单关系。
4. **从岗位还原流程线索**：搜索历史/现行研发、工艺、品质、采购、销售、售后、财务、IT岗位。保留招聘日期、岗位职责与工具名，只生成流程假设；供应商推广稿也不能证明系统实际在用。
5. **核验技术资产与资质**：按申请人/权利人及曾用名查专利、软著、认证、科技名单。分别记录申请、公开、授权、转让、失效等状态及日期；核对当前权利人、证书期限、名单“拟认定/备案/最终认定”阶段。不要把镜像目录或看似官方的域名当政府原件。
6. **补充市场和风险**：同产品、同应用、同客群选择可比企业。查公开采购、处罚、经营异常、诉讼/执行等与业务履约相关线索。检查同名、案件阶段及是否结案；涉诉不自动代表违法。法律结论超出本技能范围。
7. **核查数字化条件**：ERP/MES/PLM/CRM、资料存放、文档版本、数据权限、流程标准化、员工AI使用。公开资料通常不足，写成访谈项。不能从行业或人数推断系统配置。
8. **反证与缺口收尾**：对将改变售前策略的核心结论做一次针对性反证检索，记录冲突；为每项未知安排“公开补查/访谈/客户授权资料”中的下一步。

## 可替换检索式

将 `{企业全称}` 等替换为已确认主体。关键词用于发现线索，不代表存在相应事实。

| 目的 | 检索式示例 | 核查动作 |
|---|---|---|
| 主体与别名 | `"{企业全称}"`、`"{信用代码}"`、`"{企业全称}" 曾用名` | 回到登记或可信原始披露 |
| 政府与资质 | `"{企业全称}" site:gov.cn`、`"{企业全称}" 高新技术 认定` | 打开附件，定位完整名称、批次、页码及日期 |
| 产品与业务 | `"{企业全称}" 产品 手册`、`"{已验证品牌}" {产品类别}` | 区分发布主体、自述与第三方报道 |
| 招聘与流程 | `"{企业全称}" 招聘 研发`、`"{企业全称}" 质量 采购` | 日期、职责、历史状态；不推断现有人数 |
| 知识产权 | `"{企业全称}" 专利`、`"{企业全称}" 软件著作权` | 原始记录、标识、申请人/当前权利人、法律状态 |
| 交易与风险 | `"{企业全称}" 中标`、`"{企业全称}" 行政处罚` | 完整主体、日期、角色、处理阶段 |
| 官网候选 | `"{企业全称}" 官网`、`"{候选域名}" "{企业全称}"` | 主体关联；打不开不推定公司停业 |

搜索引擎可做多组发现检索，随后读原文。优先现有搜索/连接器工具；不将某个供应商工具写为强依赖。需登录时停止该渠道并报告限制，继续其他公开渠道。PDF表格无法可靠提取时看对应页，OCR数字必须对照原页。只保留必要短摘录与链接，不复制整份第三方报告。

## 覆盖矩阵

| 维度 | 最小字段 | 售前用途 |
|---|---|---|
| 工商/股权/管理 | 主体、登记状态、股权和高管公开信息、变更时点 | 判断接洽主体；法人未必是项目决策人 |
| 经营/规模 | 收入若公开、人员口径、厂区、产能来源 | 估计组织复杂度；资本与招聘人数不能替代经营数据 |
| 产品/客户/渠道 | 主要产品、技术资料、客群、销售模式、交付方式 | 区分研发、销售与服务需求 |
| 组织/流程 | 岗位职责、工作产物、协作环节 | 形成流程假设和访谈对象清单 |
| 技术/资质 | 专利来源、状态、软著、认证范围和期限 | 识别知识密度与专业边界 |
| 竞争/交易/风险 | 可比企业、交易信号、公开异常及阶段 | 理解差异化、履约和方案限制 |
| 数字化/AI | 系统、数据、权限、现有AI、负责人与预算 | 确认集成和部署条件，通常待访谈 |

## 深度与停止条件

- 速览：以主体、业务、3个机会假设及关键缺口为主，写明未覆盖维度。
- 标准：逐项覆盖矩阵；重要断言验证到原文，优先机会有独立佐证或明确降级。
- 深入：用户需要报价或专项验证时，扩大技术资产、交易、竞争及客户授权资料分析。
- 核心维度均有证据或明确缺口，重要冲突已列出，且连续两轮有针对性的补查没有新增会改变机会排序的信息时，可以结束公开检索。达到用户时间预算也应停止并标记未完成。不能用搜索页数宣称“所有公开资料已齐全”。
