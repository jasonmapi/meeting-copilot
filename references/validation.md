# 1.0.0 验证记录（2026-11-09）

## 已实际验证

- Skill结构校验、Python语法编译。
- Windows x64、Python3.11.9，在全新目录创建独立venv，通过pip安装faster-whisper1.2.1、sounddevice0.5.6及相关依赖；未复用既有测试设备配音环境。
- 模型通过已核验的本地CTranslate2权重目录导入，CPU int8加载成功，并对合成音频实际执行推理。合成音频不用于准确率评价。正常在线下载分支未在本次重复下载整份权重。
- 安装器重复执行更新代码，保留自定义ASR、API配置和已导入资料；生成Windows启动脚本与Mac启动脚本。
- 合成企业报告导入，文件备份、元数据与新企业会话；现场助手能显示企业名与报告入口。
- 实际启动独立HTTP服务，默认端口被其他服务占用时明确拒绝启动；改用8876后正常。未停止占用8766的其他服务。
- 模拟SSE模型服务的端到端：报告进入请求，文本→三块建议/成果/问题完成，证据不在转写中则不采纳；新一场清空/历史保留、旧请求隔离、密钥不回显。
- Edge浏览器实际连接该独立服务：建议、问题自动标绿、清空、报告链接、390px无横向溢出、无JS异常。另有隔离smoke测试，不调用付费API或麦克风。
- run.py --stop关闭本实例，部署测试服务已退出。当前既有测试设备生产现场助手未因本次打包被更新或重启。
